# Dylan Huang 的 AI Agent 协作心法

一套面向个人开发者、学生和小型团队的 AI Agent 项目协作工作流。

## 这套方法解决什么问题

- 需求不清就开始写代码
- AI 自行猜测文件、接口和架构
- 忽略已有开源方案，过早自研
- 修改范围越来越大
- 没有独立审查和可验证的验收标准
- 长对话结束后无法继续
- 第一版 MVP 被后续修改破坏

## 推荐流程

1. 配置项目协作指令，明确最小假设、最小改动和验证要求
2. 明确目标用户、任务边界和成功标准
3. 先分析问题，不立即写代码
4. 调研现有开源项目、Skill 和组件
5. 比较直接使用、基于现有方案修改和自己开发
6. 确认方案后再实现最小 MVP
7. 使用独立上下文审查需求和方案
8. 根据任务复杂度选择模型
9. 完成 MVP 后建立可恢复存档
10. 用 HANDOFF.md 延续长周期项目

## 快速开始

把 [CUSTOM-INSTRUCTIONS.md](CUSTOM-INSTRUCTIONS.md) 放入你的 Codex 项目指令中，再按 [WORKFLOW.md](WORKFLOW.md) 执行。可复制的提示词在 `prompts/`，交接和归档模板在 `templates/`。
